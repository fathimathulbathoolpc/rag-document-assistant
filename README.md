# RAG Document Assistant

A Python project that allows users to ask questions about PDF documents and receive answers based on the information found in those documents.

## Project Goal

Learn and implement Retrieval-Augmented Generation (RAG) step by step, with a focus on readable code and reliable answers.

## Planned Features

- Extract text from PDF documents
- Split text into smaller chunks
- Create embeddings for semantic search
- Retrieve relevant document sections
- Generate answers using a language model
- Show the sources used to answer questions

## Technology

- Python
- ChromaDB
- Embedding models
- A large language model (LLM)

## Status

Currently in development. Features will be added and documented incrementally.
